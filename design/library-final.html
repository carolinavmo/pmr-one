THREE HEIGHTS

PEEK · 64px
HALF · 55%
FULL · all but a strip
  • 1Peek — a 64px navy bar: progress ring, page title, section, and ▴. The tree has the whole sidebar. Tapping anywhere on the bar raises the dock to half.
  • 2Half — the default when a page opens. Tree above, contents below, both scroll independently. Tapping another page in the tree swaps the dock's contents.
  • 3Full — for long pages. The tree collapses to a slim strip — "▴ Show the library" with the current path — so browsing is always one tap away.
  • 4Moving between them — drag the grip, or use the ▾ / ▴ buttons. Heights snap to the three positions, never in between. Keyboard: Ctrl ↑ / Ctrl ↓.
  • 5The dock remembers the height you last chose and opens there next time.
NO "BACK" NEEDED

The library never disappears — at worst it is a strip at the top. Leaving a page is just scrolling the tree.

ONE PAGE IN THE DOCK

Opening a different page replaces the dock's contents. The previous page keeps its progress in the tree.

INDEPENDENT SCROLL

Tree and dock each scroll on their own. The dock auto-scrolls to keep the current section in view.

SNAP, DON'T DRIFT

Three fixed heights only. A dock that can stop anywhere feels unfinished and is harder to return to.
