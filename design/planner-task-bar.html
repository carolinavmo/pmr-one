Anterior cord syndrome

Neurology › Spinal cord injury · reviewed Aug 2026 · 12 min read

Anterior cord syndrome follows injury to the anterior two-thirds of the spinal cord, the territory of the anterior spinal artery. Motor function and pain and temperature sensation are lost below the level, while the dorsal columns — proprioception, vibration and fine touch — are preserved.

The dissociation is the diagnosis: weakness with absent pin-prick but intact position sense. Light touch travels in both systems and is often preserved, so it cannot be used to make the distinction…

WHEN A TASK COUNTS AS DONEone rule per type, and always a manual override

TASK TYPECOMPLETES AUTOMATICALLY WHENMANUAL OVERRIDE
Read a page The reader reaches the end of the page and has been on it for at least 30 seconds — so a fast scroll does not count. Mark as read in the task bar, in the left rail, or the end-of-page block.
Flashcards The session ends — every card in it has been graded. Leaving early keeps the task open, with "12 of 20 done" shown on the task row.
Questions The set is submitted, or every question in the session has been answered. Same — partial progress is kept and shown.
Course lesson The lesson is finished, using the course's own completion rule. Checkbox on the task row.
Something else Never — there is nothing to observe. The checkbox is the only way, which is why custom tasks always show one.
START OPENS THE THING

No intermediate screen. The page, the session or the question set loads with the task bar pinned above it — position in the day, skip, back, and complete.

YES, IT MARKS ITSELF

Reaching the end of a page, finishing a session or submitting a set completes the task. The manual controls exist for offline work and for pages you only needed half of.

WHY NOT JUST A SIDEBAR CHECKBOX

A checkbox on reading pages would solve one type out of five, and would sit in a rail that means something different in every feature. The task bar is one component, everywhere.
